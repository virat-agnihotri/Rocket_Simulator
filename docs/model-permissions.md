## Decision and evidence

NASA: reviewed [official media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/), collection README, repository meta.json, relevant adjacent text, and available GLB rights metadata. No MIT license is required to apply NASA’s explicit media permission. Credit NASA; no endorsement; separate identifier and marked third-party rights remain protected. Generic contributor credit is used where an individual creator is not identified.

Starship full stack: embedded creator/license/source metadata was independently corroborated by the search-indexed [exact original creator listing](https://sketchfab.com/3d-models/spacex-starship-ship-24-booster-7-v4-97875d14b63e4b9ca9ed425ef4253306). CC BY 4.0 supports the integration with creator credit, source/license links and changes disclosure. Direct Sketchfab requests returned 403; this limitation is recorded.

Other Starship files have neither verified creator attribution nor model-specific license. The two repositories lack a repository license; the older README states model credits pending. These files are excluded, without deleting their archives.

NASA archival sources/printing parts are not automatically converted into new selectable vehicles. Existing complete NASA models remain available; extra parts, alternate print models, and unsupported MAX/DWF/BLEND sources are indexed without replacing SLS or fabricating vehicle assemblies.

## Inspection limits

- Sketchfab direct page and API requests returned 403; original exact-model creator and attribution license corroborated using search-indexed original listing and embedded downloaded metadata
- NASA meta.json labels repository NOSA 1.3; assets are evaluated under explicit README and official media usage terms rather than assuming a software license replaces those terms
- 7z container contents require separate inspection; no assets imported from them
- Permission unclear is not a determination that an asset is forbidden

The SLS complete `.7z` archives expose a BLEND source and an alternate printing STL; filenames were inspected with the installed archive reader. The split scanline archive was copied into a temporary combined container, but the reader reported an unsupported LZMA codec. Its internal file metadata was not claimed verified. Unrelated 7z containers remain indexed without expansion.
